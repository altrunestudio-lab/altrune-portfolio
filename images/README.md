# Portfolio images

Upload portfolio images to this folder. The website discovers them automatically after GitHub Pages rebuilds.

## Filename format: Project name - Client - Location - Year - hero.ext

- Gallery card: `The spire - london.jpg`
- Hero slide: `The spire - london - hero.jpg`

Everything before the first ` - ` is the project name. Everything after it is the location. Add ` - hero` immediately before the extension to include that image in the top hero slideshow.

Supported formats: JPG, JPEG, PNG, WEBP, AVIF and GIF.
